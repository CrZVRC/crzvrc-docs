# Setup

:::info[Licensed with the CrZVRC License Manager]
This asset comes with the [License Manager](/docs/documentation/licence). You can add it to your world and try it right away, but you must validate your product license with the License Manager before you can publish your world.
:::

Getting the Security System into your world is a single step.

---

1. **Locate the prefab:** In your Project window, find the **`SecuritySystem`** prefab under `SecuritySystem/Prefabs`.

2. **Drag it into your scene:** Drop it into your scene hierarchy, position it wherever you'd like the management panel to appear, and you're done.

That's it — the prefab already comes with everything wired together and ready to go:

* The **security panel** (`SS_SecuritySystemUI`), for viewing and managing every player's roles.
* The **security keypad** (`SecurityKeypad`), for granting roles by password.
* **Three showcase role actions** — one each of Teleport, Toggle Objects, and Animation Trigger — already linked up so you can see how role-triggered actions work out of the box.

Everything inside the prefab is already linked to everything else. From here, head to [Roles](./roles.mdx) to start defining your own roles, or check out the showcase actions already set up on the prefab to see how [Actions](./actions.mdx) work before building your own.
