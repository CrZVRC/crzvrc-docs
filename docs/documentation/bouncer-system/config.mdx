# Configuration

The `BS_Config` class holds the global constants for the Bouncer System: the number of players it can track and the security levels used throughout its logic.

If you need to increase the maximum number of players the system can track, or reference the security levels in your own Udon scripts, you will find those values defined here.

*   **`PLAYER_CAPACITY`**: The maximum number of players the Bouncer System can track and synchronize. The default is `15`. **Note:** If your VRChat world allows for more than 15 players, increase this integer to match your world's maximum instance capacity. Players beyond the capacity are not tracked.
*   **`SECURITY_LEVEL_NONE`** (`-1`): The default state. Represents a standard player with no security privileges.
*   **`SECURITY_LEVEL_TEMPORARY`** (`0`): A player who has been granted temporary security access during the active instance (for example, a normal player promoted by another security member).
*   **`SECURITY_LEVEL_PERMANENT`** (`1`): A player with permanent security access — the Instance Owner (when enabled), or a user listed as **Security** on the whitelist (typed in the Inspector or fetched from your online URL).

:::tip[After changing PLAYER_CAPACITY]
Each panel's list of player cards is built in the Editor to match `PLAYER_CAPACITY`. After changing it, click the GameObject holding `BS_BouncerUI` in your Hierarchy once so its Inspector redraws and the cards are rebuilt to match.
:::
