# タグの割り当て

プレイヤーにタグを与える方法は 2 通りあり、どちらか一方だけでも、両方組み合わせても構いません。両方使う場合は、1 つのリストに統合されます。

---

## 手動での割り当て（Users リスト）

`PL_PlayerTags` スクリプトの **Users** リストを使うと、Editor 上で直接タグを割り当てられます。この機能には in-world のパネルは不要です。

各行には 2 つのフィールドがあります。

*   **タグのポップアップ**: [Tags リスト](./config.mdx) にあるすべてのタグが表示されます。
*   **プレイヤー名フィールド**: プレイヤーの正確な VRChat 表示名です。

このリストは Editor 上でのみ変更できるため、変更するにはワールドの再アップロードが必要です。プレイヤータグにはライブ管理パネルはありません。

---

## リモートホワイトリスト（任意）

手動リストの代わりに、あるいはそれと併用して、外部のテキストファイル（Pastebin など）からタグを割り当てることもできます。ワールドの読み込み時に自動的に取得されます。

*   **`User List Url`**: リストの **raw** URL です。Pastebin でペーストを作成し、**Raw** ボタンをクリックして、ブラウザのアドレスバーから URL をコピーします（`https://pastebin.com/raw/...` のような形式になります）。

1 行に 1 エントリの形式で記述します。

```
PlayerName, TagName
```

例:

```
CrZ, Admin
FriendOne, DJ
FriendTwo, Bartender
```

*   カンマの後のタグ名は、[Tags リスト](./config.mdx) にある名前のいずれかと完全に一致している必要があります。認識できないタグ名は、プレイヤーに何のエラーも発生させることなく、単純にスキップされます。
*   取得されたエントリは、手動の Users リストと同じ統合リストの **末尾** に追加されます。

---

## 統合リストの解決方法

両方のソースは 1 つのリストにまとめられ、**手動のエントリが先、リモートのエントリが後** の順で確認され、**最初に一致したもの** が採用されます。同じプレイヤー名が手動リストとリモートホワイトリストの両方にある場合、手動のエントリが優先されます。

知っておくと良い点がいくつかあります。

*   **一致判定は VRChat の表示名の完全一致で行われます。** プレイヤーが表示名を変更すると、以前の名前で登録されていたエントリとは一致しなくなります。
*   プレイヤーが参加した時点ですでにエントリが存在する場合と、参加後にリモートリストの読み込みが完了する場合のどちらでも、同じように解決されます。どちらの経路でもタグが付与される可能性があります。
