# 設定

プレイヤータグの設定はすべて、`PL_PlayerTags` という 1 つのスクリプトにまとまっています。シーンのヒエラルキーでこのスクリプトを持つ GameObject を選択すると、このページで説明するすべての項目が見つかります。

プレイヤータグはすべての処理を各クライアント上でローカルに実行します。ネットワーク通信は一切行われないため、プレイヤー間で同期する必要のある項目はありません。

---

## Tags

**Tags** リストは、ワールドで表示できるすべてのタグを定義します。追加できる数に決まった上限はありません。

各行には 2 つのフィールドがあります。

*   **Name**: タグの表示名です。プレイヤーにタグを割り当てる際にここから選択し、[リモートホワイトリスト](./tag-assignment.mdx) を使う場合はここで入力した名前をそのまま記述します。
*   **Template**: プレイヤーがこのタグを持っているときに、頭上にインスタンス化される GameObject です。他のワールド内 UI と同じように作成できます。Canvas、テキスト、画像など、タグに見せたい見た目を自由に作ってください。

:::warning
タグの Template は、**スクリプトが一切付いていないプレーンな GameObject**（`UdonBehaviour` を含まないもの）である必要があります。プレイヤータグはこれを実行時に直接インスタンス化し、その `Transform` の操作と `SetActive` の呼び出ししか行いません。スクリプト付きのテンプレートはサポートされていません。
:::

プレイヤーが同時に表示できるタグは **常に 1 つだけ** です。すでにタグを表示しているプレイヤーが別のタグの条件を満たした場合、古いタグは自動的に新しいタグに置き換わります。古いタグを自分で削除する必要はありません。

---

## Positioning

*   **`Y Offset`**（デフォルト: `0.3`）: タグがプレイヤーの頭上どれだけ浮くか（メートル単位）です。
*   **`Rotation Mode`**: タグの回転方法です。次のいずれかを選択します。
    *   **`None`**: 一切回転しません。Template が作られたときの向きをそのまま保ち、プレイヤーの頭の位置にのみ追従します。
    *   **`With Player`**: タグを着けているプレイヤーと一緒に回転し、まるで固定されているかのように動きます。常に直立した状態を保つため、プレイヤーが上や下を見てもタグが前後に傾くことはありません。
    *   **`To Local Player`**: 見ている人の目の動きに追従する看板のように、タグは常にそれを見ている人の方を向きます。これを行うために左右にしか回転せず、見ている人の身長や視点の角度に関わらず、上下に傾くことはありません。この判定は見ている人ごとに個別に計算されるため、同じタグを異なる方向から見ている 2 人のプレイヤーは、それぞれ自分の方を向いているように見えます。

タグはプレイヤーの頭にリアルタイムで追従します。毎フレーム再計算されるため、移動、ジャンプ、しゃがみにも追従します。

---

## Performance

*   **`Max Visible Distance`**（デフォルト: `25`）: これより遠く（メートル単位）離れたタグは更新が止まり、非表示になります。十分近づくと即座に再表示されます。これにより、多数のタグ付きプレイヤーがいるワールドでも、この 1 つの数値以外の設定なしで、スムーズな動作を保てます。**`0`** に設定すると、この機能を無効にして、距離に関係なく常にすべてのタグを表示します。

---

## Visibility

*   **`Show Own Tag`**（デフォルト: オン）: プレイヤーが **自分自身** の頭上に浮くタグを見られるかどうかです。他のプレイヤーにだけタグを見せたい場合はオフにしてください。たとえば鬼ごっこ系のミニゲームの「鬼」タグのように、他のプレイヤー全員には見えてほしいが、本人には常時表示による視覚的な気づかいをさせたくない場合に便利です。オフにしてもパフォーマンス上のデメリットはありません。非表示のタグは、作成してから隠すのではなく、そもそもそのプレイヤー用に作成されないためです。
