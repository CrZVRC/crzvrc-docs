# セットアップ

:::info[CrZVRC ライセンスマネージャーで認証します]
このアセットには[ライセンスマネージャー](/docs/documentation/licence)が付属しています。すぐにワールドに追加して試すことができますが、ワールドを公開するには、ライセンスマネージャーで製品ライセンスを認証する必要があります。
:::

Security System をワールドに導入する手順は、たった 1 ステップです。

---

1. **プレハブを見つける:** Project ウィンドウで、`SecuritySystem/Prefabs` にある **`SecuritySystem`** プレハブを探します。

2. **シーンにドラッグする:** シーンのヒエラルキーにドロップし、管理パネルを表示したい位置に配置すれば完了です。

これだけです — このプレハブには、必要なものがすべて最初から連携済みの状態で組み込まれています。

* **セキュリティパネル**（`SS_SecuritySystemUI`）— すべてのプレイヤーのロールを閲覧・管理するためのものです。
* **セキュリティキーパッド**（`SecurityKeypad`）— パスワードでロールを付与するためのものです。
* **3 つのショーケース用ロールアクション** — Teleport、Toggle Objects、Animation Trigger をそれぞれ 1 つずつ、あらかじめ接続済みの状態で用意されており、ロールに連動したアクションがどのように動作するかをすぐに確認できます。

プレハブ内のすべての要素は、あらかじめ互いにリンクされています。ここから先は、[Roles](./roles.mdx) に進んで独自のロールを定義し始めるか、プレハブにあらかじめ用意されているショーケース用アクションを確認して、自分で構築する前に [Actions](./actions.mdx) の仕組みを把握しておきましょう。
