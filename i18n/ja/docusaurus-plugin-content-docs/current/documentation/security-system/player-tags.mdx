# Player Tags

:::info[オプション]
このページはオプションの連携機能について説明しています。下記の **Player Tags** フィールドを空欄のままにしている場合、または Player Tags アセット自体をインストールしていない場合、すべてのロールの **Player Tag** ドロップダウンには単に **「No Player Tags」** と表示されるだけで、他に設定すべきことは何もありません — どちらの場合でも Security System はまったく同じようにエラーなく動作します。
:::

ワールドに別売りの **[Player Tags](/docs/documentation/player-tags/config)** アセットも導入されている場合、各ロールはそのロールの付与・剥奪と同時に、プレイヤーの頭上に浮かぶタグを自動的に表示・非表示にできます — タグとは何か、どのように作るかについては、そのアセット自身のドキュメントを参照してください。

---

## セットアップ方法

1. `SS_RolesManagement` の、Inspector 最下部にある専用の「Player Tags」ヘッダー配下の **Player Tags** フィールドに、ワールドの `PL_PlayerTags` オブジェクトをドラッグします。
2. タグを表示したい各ロールについて、そのロールの **Player Tag** ドロップダウン([ロールを定義する](./roles#defining-a-role) を参照)からタグを 1 つ選びます — ここには、あなたの Player Tags 側の設定で現在定義されているすべてのタグが一覧表示されます。

---

## 一度に表示できるタグは 1 つだけ

プレイヤーは常に 1 つのタグしか表示しません(Player Tags 自身のドキュメントを参照)。あるプレイヤーが、それぞれ *異なる* Player Tag が設定された 2 つのロールを保持している場合、実際にどちらのロールが先に付与されたかに関わらず、表示されるタグは常に [ロール階層](./roles#role-hierarchy-parentchild) 上でより上位にあるロール(もう一方を要求している側のロール)のものになります。どちらのロールも互いを要求していない場合は、Roles リストで下にある方が優先されます。
