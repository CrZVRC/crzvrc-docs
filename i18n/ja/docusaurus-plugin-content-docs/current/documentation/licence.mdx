# ライセンスマネージャー

私のすべてのアセットには、**CrZVRC ライセンスマネージャー**が付属しています。ライセンスマネージャーは、ストア（Jinxxy または Booth）からダウンロードするパッケージに含まれているため、別途インストールする必要はありません。

アセットはすぐにプロジェクトに追加し、ワールドに配置して、自由に試すことができます。**ただし、ライセンスマネージャーでライセンスを認証するまで、ワールドを公開（パブリッシュ）することはできません。**

:::warning[ワールドの公開にはライセンスの認証が必要です]
ワールドを公開するとき（**Build & Publish**、**Build & Test**、または VRChat SDK からのアップロード）、ライセンスマネージャーはシーン内のすべての CrZVRC アセットをチェックします。お使いのアカウントでライセンスが有効になっていないアセットがある場合、ビルドは**キャンセル**され、ライセンスが不足しているアセットがメッセージで表示されます。ライセンスを認証すれば、通常どおり公開できます。

このチェックは、公開するときに Unity エディター内でのみ行われます。ワールド内では何もチェックされず、ワールドを訪れる人に影響はありません。
:::

以下は、ライセンスを認証するための完全なステップバイステップガイドです。

---

## 1. ライセンスマネージャーを開く

アセットの `.unitypackage` を Unity プロジェクトにインポートした後:

1. Unity の上部メニューバーを確認します。
2. **CrZVRC** > **License Manager** をクリックします。
3. ライセンスマネージャーのウィンドウが開き、Unity のレイアウトにドッキングされます。

---

## 2. アカウントの同期（初回のみのセットアップ）

ライセンスを認証する前に、VRChat アカウントを私のプラットフォームと同期する必要があります。**この作業は一度だけ行えば済みます。**

:::caution 
Unity プロジェクト内で **VRChat SDK** のコントロールパネルにログインしている**必要があります**。ライセンスマネージャーは、SDK から直接、安全かつ自動的にあなたの VRChat User ID を抽出します。
:::

**同期の手順:**

1. **VRChat ID を確認する:** ライセンスマネージャーが自動的にあなたの VRChat User ID を取得して表示します。
2. **メールアドレスを入力する:** 使用したいメールアドレスを所定のテキストフィールドに入力します。
3. **コードをリクエストする:** **Send Login Code** ボタンをクリックします。
4. **認証する:** メールの受信トレイで 6 桁のコードを確認します。このコードをライセンスマネージャーに入力し、**Verify Code** をクリックします。

---

## 3. ライセンスの登録

### ライセンスキーの取得

*   **Jinxxy での購入:** ライセンスキーは、購入時にストアページまたは領収書に自動的に提供されます。
*   **Booth での購入:** Booth はライセンスキーを自動的に生成しません。キーを取得するには、[Discord サーバー](https://discord.com/invite/3W7h3Bp3mH)に参加し、サポートチケットを開いて購入の証明を提出してください。私が手動でライセンスキーを生成してお送りします。

### アセットの認証

1. **Activate New Asset** セクションで、アセットを購入した**ストア**（Jinxxy または Booth）を選択します。
2. ライセンスキーを入力して **Register License** をクリックします。
3. 登録が完了すると、製品が **Activated Assets** リストに表示されます。これでライセンスが認証され、そのアセットを使用したワールドを公開できるようになります。

---

## 4. ライセンスが認証される前に表示されるもの

*   **インスペクターで:** アセットに、お使いのアカウントでライセンスが有効になっていないことを示す赤い通知と、**Open License Manager** ボタンが表示されます。
*   **公開するときに:** ビルドがキャンセルされ、ライセンスが不足しているアセットを一覧にした **Build blocked: license required** のメッセージが表示されます。

解決するには、ライセンスマネージャーを開いてログインし、ライセンスキーを登録する（すでに登録済みの場合は **Fetch** を押す）と、もう一度公開してください。

---

## 5. ライセンスの認証状態を維持する

*   チェックに成功すると、ライセンスはお使いのコンピューターに記憶されます。保存されるデータには署名が付いているため、手動で編集することはできません。
*   Unity の起動時（保存されたデータが 12 時間以上前のものである場合）にバックグラウンドで自動的に更新されるほか、ログイン、**Fetch** の押下、キーの登録のたびにも更新されます。
*   最後にチェックに成功してから**最大 7 日間は、インターネットに接続していなくても**公開を続けられます。それ以降は、オンラインの状態でライセンスマネージャーを開き、**Fetch** を押してください。
*   ライセンスマネージャーから **Logout** すると、公開する前にもう一度ログインする必要があります。
*   **停止または取り消された**ライセンスは無効となり、そのアセットを使った公開はブロックされます。
*   ライセンスマネージャーはプロジェクト内に残しておく必要があります。削除すると、私のアセットを使用したワールドの公開がブロックされます。

---

## 6. アセットのダウンロードと更新

アクティベート済みのアセットは **Activated Assets** に一覧表示されます。アセットの横にある **Import** をクリックすると、最新バージョンがプロジェクトに直接ダウンロードされます。その後、ライセンスマネージャーが `.unitypackage` のインポートを求める標準の Unity ダイアログを開きます。

---

## 7. ライセンスマネージャーの更新

ライセンスマネージャーのバージョンは、ウィンドウの下部に表示されます。Unity の起動時とウィンドウを開いたときに新しいバージョンを確認するほか、**Check for updates** ボタンでいつでも確認できます。

*   **黄色のバナー（更新あり）:** 新しいバージョンがあります。ご都合のよいときに **Update License Manager** をクリックしてください。その間も公開は続けられます。
*   **赤色のバナー（更新が必須）:** このバージョンは、たとえばセキュリティ修正のため、使用できなくなりました。更新するまで、私のアセットを使用したワールドの公開はブロックされます。

更新が自動的にインストールされることはありません。**Update License Manager** をクリックしたときにのみ更新が行われます。更新をダウンロードしてインポートし、その後 Unity がスクリプトを再読み込みします。

---

:::danger
ライセンスは、同期プロセス中に使用した **VRChat User ID** に永続的に紐付けられることにご注意ください。

この直接的な紐付けのため、**何らかの理由で VRChat アカウントへのアクセスを失った場合（ログイン情報の紛失、アカウントの削除、BAN など）、購入したアセットへのアクセスも失われます。**

ライセンスは一度登録されると別の VRChat アカウントへ移行できないため、VRChat アカウントを安全に保つようにしてください。
:::
