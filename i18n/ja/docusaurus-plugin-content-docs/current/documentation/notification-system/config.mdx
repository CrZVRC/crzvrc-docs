システムがキューに保持できる通知の最大数を調整できます。これは `NS_Config` スクリプトで処理されます。

---

### `NS_Config`

このクラスには、Notification System のグローバル設定定数が含まれています。

*   **`NOTIFICATIONS_QNT`**: 通知を保持するキューの最大サイズを定義します。デフォルトでは `5` に設定されています。この整数を変更して、キューに入れられるメッセージの最大数を増減します。
